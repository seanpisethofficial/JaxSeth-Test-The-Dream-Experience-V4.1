# 🇰🇭 Anti-Cheat — មេរៀន

Anti-cheat ត្រូវប្រើជាច្រើនស្រទាប់។

## Signals

- Remote Spam
- Invalid Interaction
- Permission Violation
- Impossible State
- Movement Anomaly
- Economy Anomaly
- Repeated Invalid Requests

## Response

IGNORE
→ LOG
→ THROTTLE
→ BLOCK ACTION
→ ESCALATE

## សំខាន់

កុំ Ban ដោយ signal មួយដែលអាចមាន False Positive។

Movement detection ត្រូវគិតពី:

- Respawn
- Server Teleport
- Vehicle
- Cutscene
- Developer tools
- Legitimate movement
